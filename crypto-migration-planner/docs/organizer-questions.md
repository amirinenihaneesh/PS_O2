# Information Required From Organizers

The supplied participant instructions identify PS-P2 by title, but the PS-P2 specification and starter kit are not present in the available files. Please request these items from the Hackathon & Competitions Cell or the PS-P2 track contact.

1. **PS-P2 source of truth:** the complete problem statement, version/date, mandatory constraints, and any amendments.
2. **Starter pack:** the official repository template, notebook or scripts, example files, schemas, and setup instructions.
3. **Inventory contract:** required input fields and formats, supplied dataset or test cases, required outputs, and expected handling of unknown or invalid records.
4. **Assessment and migration rules:** the required algorithm classification, quantum-risk treatment, score/priority formula and thresholds (if any), reference baseline, and approved migration recommendations or mappings.
5. **Processor A/B files:** exact machine-readable definitions, noise assumptions, supported backend/simulator APIs, software versions, and benchmark instructions.
6. **P2-to-processor connection:** what workload or circuit PS-P2 must run on A and B, how the result relates to the crypto inventory/planner, and which settings must remain identical.
7. **Evaluation:** required PS-specific and architecture/resource metrics, result schema, repetitions/seeds/shots where applicable, graph/table requirements, and any rubric weights.
8. **Submission rules:** exact repository structure/naming, report and notebook requirements, deadlines or upload format, and the full AI-assistance disclosure policy.

## Why These Answers Matter

- Without the PS-P2 schema and expected behavior, an inventory format or migration workflow would be an assumption.
- Without official prioritization rules, numeric scores or rankings could misrepresent the challenge.
- Without approved purpose-specific replacement mappings, recommendations could be technically inappropriate.
- Without A/B definitions and a P2 benchmark workload, a processor comparison cannot be reproduced or claimed as official.
- Without the starter pack and evaluation rubric, repository compliance and required metrics cannot be verified.
